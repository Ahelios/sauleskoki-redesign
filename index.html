Before any version goes live

  • Check the new Latvian texts. A few short lines are new (hero subtitle, "Kā strādājam" steps, photo captions, team text). Everything else is copied from the current site.
  • Upload og-image.jpg to the site root. It is the picture Facebook / WhatsApp show when someone shares the link. The live site points to it, but the file is missing today.
  • Add the analytics script back (pulse.sauleskoki.lv). It was left out so local previews don't count as visits.
  • Copy the img/ folder to the server next to the chosen page, and update the image paths from ../img/ to img/.
  • Version 10 has new Latvian text in the "Kad zvanīt?" section — four short season descriptions, including the line about the 15 April – 30 June felling restriction in towns and villages. They are a draft written by the AI, not copied from the site. Eduards should check every sentence there before it goes live.
  • Version 13 has no FAQ on the page, so its code also leaves out the FAQ markup for Google (the other versions keep it). Google only wants that markup when the questions are visible. Everything else in its code is the same as version 12.
  • All versions load the full-size photos from img/. Before go-live, make smaller copies (about 1600px on the long side, compressed) so the page loads fast on phones.
  • One call button per screen (changed 2026-10-03, all versions). On phones the bottom "Zvanīt" bar steps aside whenever another call button or the number is on screen, and the built-in doubles were removed: the "Zvaniet: 28 394 620" tail of the first FAQ answer (versions 1–12, also in the Google markup), call links inside the service panels (10), the "Zvaniet" row in the hero (11), "Zvanīt" on the service tiles and in the moving line (13), and the extra "Zvanīt" button next to the big number (12, 13). In version 3 the hero's call button is hidden on phones and the number button in the FAQ box is gone; in version 4 the team button scrolls to the contact card instead of dialling.
  • Fewer photos (2026-10-03). Galleries were cut to a chosen few: version 10 six, 11 six plates, 12 six, 13 four. Version 11 no longer labels the gear on the hero photo.
  • Version 12 has new short Latvian texts — the view labels ("Skats no zemes" / "Skats no galotnes"), the filter chips, "Turiet, lai redzētu pēc", "Saglabāt kontaktu" / "Kopēt numuru" / "Nokopēts", the headings "Seši darbi — viens zvans" and "Viss sākas ar zvanu", and one new sentence: "Jūs redzat koku no dārza. Mēs — arī no vainaga." All AI drafts; Eduards should check them.
  • Version 11 has new Latvian text — the six callout labels on the hero photo, the "Kā strādājam" intro and call box, and the plate captions. All of it is an AI draft; Eduards should check the wording. On purpose it describes no cutting technique and has no self-check list.
  • The Kling clip is in place. video/hero-1080.mp4 (desktop, 6.1 MB) and video/hero-720.mp4 (phones, 4.3 MB) were made from kling_20261003_VIDEO_Cinematic__165_0.mp4 with ./make-video.sh. Versions 6–8, 10, 12 and 13 play it (v6–8: hero background; v10: the second photo card; v12 and v13: the first screen). Version 11 has no video on purpose. If the chosen version uses it, upload the video/ folder next to the page. The 19.5 MB Kling original in this folder is only the source; it does not need to go on the server. If you get a new clip, run the script again.
  • The Kling clip has a small "KlingAI 3.0" watermark in its bottom-right corner. Versions 10, 12 and 13 crop it away; versions 6–8 show it faintly in the hero. Before going live with one of those, export the clip from Kling without the watermark and run the script again.
  • Versions 4 and 5 draw their trees with code. Test them on a real phone before choosing — they were checked in Chrome only.
  • Logo: each version has the logo redrawn as code (SVG), so it can animate. The old logo.svg was a picture inside an SVG and couldn't move.
